# Data Retention

## MVP Principle

Retain only data necessary for current functionality and the 7-day
history requirement.

## Planned Retention

-   Current configuration: until user changes/removes it
-   Daily usage history: minimum period needed for 7-day history; exact
    policy to be finalized
-   Temporary enforcement state: as short as practical
-   Diagnostic logs: shortest period consistent with debugging needs

## Deletion

Users should be able to remove local app data through normal Android
mechanisms. Any in-app deletion controls introduced later must be
documented here.

## Changes

Retention changes require security/privacy review and documentation
updates.
