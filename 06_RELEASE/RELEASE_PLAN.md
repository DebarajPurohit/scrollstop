# Release Plan

## Alpha

Goal: Validate core enforcement on controlled test devices.

Exit: - Core blocking loop works - Critical crashes resolved - Basic
permission recovery works

## Beta

Goal: Real-device reliability and user feedback.

Measure: - Enforcement success - Crashes - Battery impact - Activation -
Retention - Blocking failures - User feedback

## Production

Requirements: - Play declarations complete - Privacy policy/Data Safety
complete - Release testing complete - Critical enforcement scenarios
pass - Store listing ready - Monitoring/support process ready

## Post-release

Track reliability, reviews, crashes, retention, support issues and
monetization evidence before expanding scope.
