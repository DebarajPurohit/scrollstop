# Google Play Checklist

## Product

-   [ ] App purpose clearly described
-   [ ] Store listing matches actual behavior
-   [ ] No misleading claims

## AccessibilityService

-   [ ] Correct API usage
-   [ ] Required disclosure completed
-   [ ] User-facing explanation/consent
-   [ ] Service limited to documented enforcement purpose
-   [ ] No accessibility-tool claim unless product actually qualifies

## Permissions

-   [ ] Usage Access handling documented
-   [ ] Accessibility handling documented
-   [ ] Package visibility reviewed
-   [ ] Minimum necessary permissions

## Privacy

-   [ ] Privacy policy published
-   [ ] Data Safety information matches implementation
-   [ ] Data collection reviewed
-   [ ] Retention reviewed

## Technical

-   [ ] Current target API requirement satisfied
-   [ ] Production signing configured
-   [ ] Release build tested
-   [ ] Crash monitoring ready
-   [ ] Real-device testing complete

## Final

-   [ ] Store screenshots
-   [ ] App description
-   [ ] Support contact
-   [ ] Content declarations
-   [ ] Release notes
