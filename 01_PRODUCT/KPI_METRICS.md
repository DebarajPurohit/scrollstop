# KPI Metrics

## Product

-   Activation rate
-   First app configured
-   First limit created
-   Day 1 / Day 7 / Day 30 retention
-   Limits reached per active user
-   Protected apps per user

## Reliability

-   Successful enforcement rate
-   Accessibility interruption rate
-   Usage Access failure rate
-   Permission recovery rate
-   Crash-free sessions

## Performance

-   Battery impact
-   Startup latency
-   Blocking response latency

## Business

-   Free-to-premium conversion
-   Subscription retention
-   Revenue
-   Refund rate

## User Feedback

-   Play Store rating
-   Reviews
-   Support requests
-   Blocking-failure reports

Metrics must be defined with a clear population and time period before
being used for decisions.
