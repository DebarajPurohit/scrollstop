# UI Specification

## Screens

1.  Welcome
2.  Permission Guide
3.  Usage Access Guidance
4.  Accessibility Guidance
5.  App Selection
6.  Limit Configuration
7.  Dashboard
8.  App Detail
9.  Blocking Screen
10. History
11. Protection Health
12. Settings

## Dashboard

Must show: - Protection status - Selected apps - Usage today - Remaining
time - Limit - Warnings - Access to health/settings

## Blocking Screen

Must clearly state: - App is currently blocked - Configured limit has
been reached - When the allowance resets, if applicable -
Protection/permission status if relevant

## UX Principles

-   Clear language
-   Minimal friction during setup
-   No deceptive UI
-   Accessible text and controls
-   Visible recovery path when protection is paused
